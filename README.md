# AutoPrice AI 🚗

> **Predict used-car prices using Machine Learning.**

AutoPrice AI is a full-stack demo ML web application. A user enters details about a used car and the application returns an estimated selling price, powered by a **Random Forest Regression** model served through a **FastAPI** backend.

---

## Architecture

```
React (TypeScript + Vite + Tailwind)
          ↓  HTTP POST /predict
FastAPI (Python · Uvicorn)
          ↓
ColumnTransformer Preprocessing Pipeline
  • OneHotEncoder → brand, fuel_type, transmission
  • Passthrough   → model_year, km_driven, engine_cc, owner_count, mileage
          ↓
RandomForestRegressor (200 trees, scikit-learn)
          ↓
Estimated Price (₹ Lakhs) + ±10% Range
```

## Installation & Running

### 1. Backend

```bash
cd auto-price-ai/backend

# Install Python dependencies
pip install -r requirements.txt

# Generate dataset + train the ML model
python train_model.py

# Start FastAPI server
uvicorn main:app --reload
```

Backend runs on: **http://localhost:8000**
Swagger docs: **http://localhost:8000/docs**

### 2. Frontend

```bash
cd auto-price-ai/frontend

# Install Node dependencies
npm install

# Start Vite dev server
npm run dev
```

Frontend runs on: **http://localhost:5173**

## ML Model Details

| Property         | Value                      |
|------------------|----------------------------|
| Algorithm        | Random Forest Regression   |
| Library          | scikit-learn               |
| Estimators       | 200 decision trees         |
| Max Depth        | 20                         |
| Training data    | 3,000 synthetic rows       |
| Target variable  | `price` (₹ Lakhs)          |

**Features used:**
- `brand` (categorical) — OneHotEncoded
- `fuel_type` (categorical) — OneHotEncoded
- `transmission` (categorical) — OneHotEncoded
- `model_year` (numerical)
- `kilometers_driven` (numerical)
- `engine_cc` (numerical)
- `owner_count` (numerical)
- `mileage` (numerical)

**Evaluation metrics** are generated from actual training and stored in `model/model_metrics.json`. The `About Model` page in the UI loads and displays them live.

## Synthetic Dataset

The dataset is generated by `generate_data.py` with realistic statistical relationships:

- Newer cars → higher prices
- More kilometres → lower prices  
- Premium brands (Toyota, Volkswagen, Skoda) → higher base prices
- Automatic transmission → ~10% premium
- More previous owners → decreasing price
- Larger engine → higher price
- ±12% random noise prevents perfectly linear data

> ⚠️ **Disclaimer:** The synthetic dataset does NOT represent actual market prices. All predictions are ML-based estimates and should not be treated as official vehicle valuations.
